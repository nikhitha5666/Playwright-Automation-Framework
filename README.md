# Playwright Automation Framework
 
An end-to-end test automation framework built with **Playwright** and **JavaScript**, implementing the **Page Object Model (POM)** pattern, REST API validation, and automated CI/CD workflows.
 
---
 
## Tech Stack
- **Language:** JavaScript (Node.js)
- **Core Engine:** Playwright Test
- **Design Pattern:** Page Object Model (POM)
- **API Validation:** Playwright `APIRequestContext` & Postman
- **CI/CD:** GitHub Actions
